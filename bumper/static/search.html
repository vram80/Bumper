Query syntax
wordOptional term. Documents matching more terms rank higher.
+wordThe document must contain the term.
-word or NOT wordThe document must not contain the term.
a OR b, a AND bExplicit operators.
"exact phrase"Words in this order.
"a b"~10Words within 10 words of each other, in any order.
obvio*Words beginning with the prefix.
enablment~Close spellings (up to 2 edits; ~1 for 1).
( ... )Grouping, e.g. (alice OR mayo) +"practical application".
field:valueFilters: examiner:, artunit:, customer:, code:, app:, filer:, prev_out:, next_out:, prev_in:, next_in:, year:. Separate several values with |, e.g. artunit:3667|3661.

Previous/next action filters use the application's full file history. For example, code:A.NE next_out:NOA finds after-final responses that were followed by an allowance.
